# Bokeh Visualisation Exercise
This repository contains the Bokeh plotting exercise using world population dataset.

## Exercise Task
Use `bokeh.plotting` to draw line charts of population density for Germany and Switzerland, and arrange plots with gridplot layout.

## Folder Structure
- `Datasets/`: raw dataset `world_population.csv`
- `Exercise9.01/`: Jupyter notebook file `Exercise9.01.ipynb`

## How to run
1. Install dependencies.
2. Launch jupyter lab.
3. Open `Exercise9.01.ipynb` and run all cells.

Visualisation files: bokeh_plot.png, Population Density of Germany and Switzerland.png
